# Accessibility requirements

Glow Material must remain usable without glow, blur, transparency, or animation.

- Maintain readable text and control contrast.
- Provide a visible keyboard focus indicator.
- Never use color or glow as the sole state indicator.
- Respect reduced-motion settings.
- Avoid flashing, pulsing, or repeated brightness changes.
- Preserve usable hit targets and window controls.
- Keep inactive-window content readable.
- Test with compositor effects disabled and alternate accent colors.

Accessibility is a release requirement.
