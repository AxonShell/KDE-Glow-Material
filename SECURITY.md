# Security Policy

Security issues may arise in build scripts, packaging, installation logic, or executable components.

## Reporting

Do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature when available. Otherwise, contact the repository owner privately through GitHub.

Include affected revisions, reproduction steps, impact, and suggested mitigation. Remove personal data from reports.

## Supported versions

Security fixes target the latest maintained version on the default branch unless a release explicitly states otherwise.
